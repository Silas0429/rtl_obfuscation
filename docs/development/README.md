# 开发文档

这里的内容面向项目维护者，不是普通用户的操作手册。用户请返回仓库根目录
[`README.md`](../../README.md)，或查看 [`docs/`](../README.md) 用户文档索引。

## 目录

- [`project_structure.md`](project_structure.md)：当前产品入口、模块职责和数据流。
- [`future_work.md`](future_work.md)：已知边界与未来可能方向，不授权当前实现自动扩展。
- [`architecture/`](architecture/README.md)：三入口架构、project-root 路线和历史设计方案。
- [`architecture/stcache_core_category_stability.md`](architecture/stcache_core_category_stability.md)：当前
  StCache 四组核心类别的服务器证据、局部验收与未解决边界。
- [`process/`](process/README.md)：重构阶段的子 Agent 规范与开发任务草案。
- [`../tasks/README.md`](../tasks/README.md)：任务合同、状态流转和验收记录。

这些文件记录实现背景和维护约束；它们不替代根目录 README 中的用户命令。
